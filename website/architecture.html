Section 2

AWS infrastructure design

One server does the work; managed AWS services around it hold the secrets, the backups, the logs and the alarms.

Solid arrows: data flows on every request or on a schedule. Dashed arrows: calls out of AWS or checks from outside the server.

How a question travels

  1. The customer opens https://13-239-67-10.sslip.io. Caddy answers on HTTPS with a free Let's Encrypt certificate.
  2. nginx logs the request (time, status, duration, app version) to /var/log/pugad/access.log, which the CloudWatch agent ships to /sam10/pugad/requests. LOGS
  3. LibreChat adds the Pugad system prompt and the 10 shop documents and sends it all to Google Gemini 3.5 Flash.
  4. The answer streams back; the conversation is saved in MongoDB on the same server.

Plan B on HTTPS. The design used CloudFront in front of the server. AWS held the account in verification for 4+ days, so CloudFront could not be created. We switched to Caddy with an automatic certificate on an sslip.io address so the site still had HTTPS. The cost of this: ports 80 and 443 are open to the whole internet instead of only to CloudFront (see security).
